3. **Новост** → (1) capture-time sealing с sha256+timestamp **е реално и работи**; (2) обвързване със събитие + пребряем CO2 одитен трак — реално, а **satellite cross-validation е преместено като задача на гранта**; (3) плащания по HTTP 402/EIP-3009 ≈ 0.005 USD — **обозначено като „work package of this grant"**, с честно „днес плащанията са Stripe Connect в тест режим".
4. **IP стратегия** → публикуваният пакет е Apache-2.0 (факт); основната платформа е проприетарна днес; **open-core AGPL е решение, което се прилага по време на проекта** (не се твърди като вече факт); EU търговска марка след регистрация на фирмата; FTO анализ = задача месец 3.

6. **Risk/traction** → махнато „20 339 верификации"; пише: *commercial traction: none yet — 0 external users, 0 revenue, 0 production deployments — which is precisely what this grant funds*.
7. **Market** → махнати „listed on Smithery", „Open Collective Europe", „already initiated pilot procedures"; JRA споменаването е махнато (сателитите са бъдеща задача).
8. Махнати са **страниците-инструкции на шаблона** (структура, история на версиите, ТК, инструкции) — шаблонът изрично разрешава това преди подаване; **заглавията са запазени**, както се изисква.
